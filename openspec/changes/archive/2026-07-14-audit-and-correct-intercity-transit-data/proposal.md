## Why

코스 일정의 장소 간 이동이 현재 좌표 직선거리와 고정 속도 공식에 의존해 실제 이동 경로보다 짧거나, 먼 장소가 8km로 표시되는 오류가 발생합니다. 모든 지원 도시의 생성 코스를 점검하고 실제 경로 데이터에 기반한 거리·소요시간을 적용해 일정 신뢰도를 높여야 합니다.

## What Changes

- 모든 지원 도시의 대표 코스에서 연속 장소 이동 구간을 추출해 전수 감사합니다.
- 장소별 실제 경로 거리와 이동시간을 보존하는 도시·장소 쌍 데이터와 출처 메타데이터를 추가합니다.
- `calculateTransit`가 검증된 경로 데이터를 우선 사용하고, 먼 장소를 임의의 8km로 축소하지 않도록 수정합니다.
- 보행·대중교통·택시 등 표시 교통수단과 10분 단위 시간 표시를 기존 UI 계약에 맞춰 유지합니다.
- 누락 좌표, 합성 좌표, 비정상적으로 짧은 이동시간, 도시 밖 장소, 중복 구간을 자동으로 실패시키는 전수 검증 스크립트를 추가합니다.
- 루트와 `deploy_live`의 런타임 파일을 동기화하고 배포 후 대표 도시와 모바일 화면을 Playwright로 검증합니다.

## Capabilities

### New Capabilities
- `city-transit-accuracy-audit`: 지원 도시 코스의 장소 간 실제 경로 거리·시간 데이터와 전수 감사 규칙을 정의합니다.

### Modified Capabilities
- `evidence-based-travel-times`: 장소 간 이동에도 검증된 실제 경로 시간이 사용되도록 범위를 확장합니다.

## Impact

- `app.js`의 장소 좌표·도시 내 이동 계산과 검증된 이동 데이터 로딩 경로
- 도시별 코스 데이터 및 새 이동 경로 데이터 파일
- 정적 데이터 감사/코스 커버리지 검증 스크립트와 npm 테스트 명령
- `index.html`, `200.html`, `deploy_live` 동기화 및 Surge 배포 산출물
